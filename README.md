# Canteen Management System

Java console application for managing a canteen with SQLite database storage.

## Features

- Add and view menu items
- Register customers
- Place customer orders
- Reduce stock automatically after each order
- View placed orders and sales summary
- Store data persistently in SQLite

## Tech Stack

- Java 17
- Maven
- SQLite JDBC

## Run

```bash
mvn package
java -jar target/canteen-management-system-1.0.0-jar-with-dependencies.jar
```

## Database File

`data/canteen.db`

## Default Seed Data

The app inserts a few sample menu items and customers on the first run.
